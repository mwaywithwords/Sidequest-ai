# Screenshots

Add product captures here when you have a running SIDEQUEST build. The main README links these filenames.

| File | Screen |
| --- | --- |
| `setup.png` | Grade and skill selection |
| `scan.png` | Camera / photo preview |
| `discover.png` | Photograph, object name, short fact |
| `connect.png` | The real property that grounds the skill |
| `challenge.png` | The grounded problem and answer entry |
| `progress.png` | Math Explorer Level, skills, objects found |

Do not commit photos of real students, faces, or private documents.
